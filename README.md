# leonardolopes.tech

Personal site of Leonardo Lopes, tech lead, software engineer and architect. It has five pages (home, about, experiences, technologies and contact), a 404 and an internal `/styleguide`. The visual direction is called "neon on midnight": dark, with cobalt and neon light.

- **Stack:** Next.js 16 (App Router, Cache Components, Turbopack), React 19 with the React Compiler, TypeScript, Tailwind CSS v4, shadcn/ui on `@base-ui/react`, three.js scenes for the light effects, Vitest and Biome.
- **Deploy:** Vercel, from `master`. Releases and `CHANGELOG.md` are generated by semantic-release.
- **Docs:**
  - `CLAUDE.md`: engineering rules and patterns. Read it before changing code, whether you are a person or an agent.
  - `DESIGN.md`: design system.
  - `PRODUCT.md`: audience, voice and positioning.
  - `PENDING.md`: open items.

## Run it locally

Requirements: Node `24.19.0` (pinned in `.nvmrc`) and pnpm (pinned in `package.json`). Do not use npm, yarn or bun.

```bash
nvm install && nvm use      # Node from .nvmrc
corepack enable             # pnpm at the pinned version
pnpm install                # also installs the lefthook git hooks
cp .env.example .env        # then fill in the values below
pnpm dev                    # http://localhost:3000
```

### Environment variables

The schema lives in `src/utils/env.ts` (zod via `@t3-oss/env-nextjs`). The build fails if a variable is missing or invalid.

| Variable | Where | What |
|---|---|---|
| `APP_URL` | server | Canonical origin (`https://leonardolopes.tech`). Used by metadata, the sitemap, robots and JSON-LD. |
| `CV_URL` | server | Public URL of the résumé PDF (Vercel Blob). |
| `NEXT_PUBLIC_SCHEDULE_LINK` | server (read as `SCHEDULE_LINK`) | Booking link for "Schedule a call". |
| `NEXT_PUBLIC_CONTACT_NUMBER` | client | WhatsApp number, international format. |

## Scripts

| Command | What it does |
|---|---|
| `pnpm dev` | Dev server (Turbopack) on :3000. |
| `pnpm build` | Production build. Fails on type errors and prints which routes are static (`○`). |
| `pnpm start -p 3100` | Serves the build. Check CSS changes here, because the dev server can keep a stale `globals.css`. |
| `pnpm lint` | `biome check --fix --unsafe .`. It **modifies files**. |
| `pnpm check-types` | `next typegen` + `tsc --noEmit`. |
| `pnpm test:run` | Vitest once, with coverage (90% minimum). |
| `pnpm test:watch` / `pnpm test:ui` | Vitest in watch mode or with the UI. |

Git hooks (lefthook):
- **pre-commit:** `lint`, `check-types` and `test:run`.
- **pre-push:** `build`, `lint` and commitlint.

CI (`.github/workflows/ci.yml`) runs on every pull request: Biome, types, build, PR title lint, audit, secret scan and tests. A push to `master` runs `release.yml` (semantic-release, `.releaserc.cjs`), which needs the `GH_TOKEN` repository secret.

Commits follow Conventional Commits with the types `hotfix, feat, fix, chore, style, refactor, doc, wip, revert, test`, in English and with a lower-case subject.

## Where things live

```
src/app/          routes (page.tsx only re-exports a screen), metadata, generated images
src/screens/      one folder per page: index.tsx (+ container.ts for client logic)
src/components/   domain components; ui/ = shadcn pieces + vendored WebGL scenes
src/utils/        pure functions and site content (mock.ts holds every fact shown)
public/brand/     portrait.svg and signature.svg: the source of every generated image
public/llms.txt   plain-text summary for AI crawlers (keep in sync with mock.ts)
test/             Vitest setup and shared helpers
```

## Common changes

- **Edit content (experiences, results, stack, links):** `src/utils/mock.ts`. Then update `public/llms.txt` and, if the summary changed, `SITE_DESCRIPTION` in `src/utils/seo.ts`. Every number must be a real one. See "Content and copy" in `CLAUDE.md`.
- **Add a page:** see "Routes" in `CLAUDE.md`.
- **Change the portrait or signature:** replace the SVG in `public/brand/`. The favicon, apple icon, OG image and badge textures are all regenerated from it at build time.
- **Change a brand color:** change it in `src/app/globals.css` (`@theme`) and in `src/utils/palette.ts`, which holds the copy used by the WebGL scenes.
